Pivot Tables

Cross-tabulation and matrix organization of data

NoteRead Inferential Thinking

Read Ch 8.3.3, which describes pivoting in detail.

Before continuing, make sure that:

  • You understand what a pivot table is and when to use it
  • You can compare and contrast how group and pivot aggregate data
  • You understand the optional arguments to the pivot method: values and collect

What is Pivoting?

Pivot tables are a powerful way to reorganize and summarize data by creating a cross-tabulation (or contingency table) that shows the relationship between two categorical variables.

While .group() produces a table with rows for each unique combination of values, .pivot() reorganizes the data into a matrix format where:

  • One variable defines the rows
  • Another variable defines the columns
  • The cells contain counts or aggregated values

This makes patterns and relationships much easier to see at a glance!

Basic Pivot Syntax

The basic syntax for pivot is:

tbl.pivot(column_for_columns, column_for_rows)

This creates a pivot table where:

  • column_for_columns: unique values become the column headers
  • column_for_rows: unique values become the row labels
  • Cells contain counts of how many rows match that combination

Example: Ice Cream Cones

Let’s look at a simple example with ice cream cone data:

from datascience import *
import numpy as np

# Create a sample cones dataset
cones = Table().with_columns(
    'Flavor', make_array('Strawberry', 'Chocolate', 'Chocolate', 'Strawberry', 'Chocolate'),
    'Price', make_array(3.55, 4.75, 6.55, 5.25, 5.25)
)
cones
Flavor Price
Strawberry 3.55
Chocolate 4.75
Chocolate 6.55
Strawberry 5.25
Chocolate 5.25

If we want to see how many cones we have at each price point for each flavor, we can use pivot:

cones.pivot('Flavor', 'Price')
Price Chocolate Strawberry
3.55 0 1
4.75 1 0
5.25 1 1
6.55 1 0

Each cell shows the count of cones that match that flavor and price combination.

Advanced Pivot: Using values and collect

The full syntax for pivot includes optional arguments for aggregating values:

tbl.pivot(column_for_columns, column_for_rows, values, collect)

Where: - values: the column name containing values to aggregate (instead of just counting) - collect: the aggregation function to apply (e.g., sum, np.mean, max)

Example: Aggregating Chocolate Data

# Create a chocolates dataset
chocolates = Table().with_columns(
    'Color', make_array('Dark', 'Milk', 'White', 'Dark', 'Milk', 'Milk'),
    'Shape', make_array('Round', 'Rectangular', 'Rectangular', 'Round', 'Rectangular', 'Round'),
    'Amount', make_array(4, 6, 12, 7, 9, 2),
    'Price', make_array(1.3, 1.2, 2, 1.75, 1.4, 1)
)
chocolates
Color Shape Amount Price
Dark Round 4 1.3
Milk Rectangular 6 1.2
White Rectangular 12 2
Dark Round 7 1.75
Milk Rectangular 9 1.4
Milk Round 2 1

Let’s find the total amount of chocolates by color and shape:

chocolates.pivot('Color', 'Shape', 'Amount', sum)
Shape Dark Milk White
Rectangular 0 15 12
Round 11 2 0

Or the average price by color and shape:

chocolates.pivot('Color', 'Shape', 'Price', np.mean)
Shape Dark Milk White
Rectangular 0 1.3 2
Round 1.525 1 0

Common collect Functions for Pivot

Here are common aggregation functions you can use with pivot:

Function Description Example Use
(none) Count rows Default behavior
sum Add up values Total sales, quantities
np.mean Calculate average Average prices, scores
np.median Find median Middle values
min Find minimum Lowest prices
max Find maximum Highest scores

When to Use Pivot vs. Group

Choosing between .group() and .pivot() depends on how you want to view your data:

Use .group() when… Use .pivot() when…
You want a simple list of combinations You want a matrix/cross-tab view
You’re grouping by one variable You’re analyzing two categorical variables
You prefer a “long” format table You prefer a “wide” format table
Order of rows matters Visual pattern recognition matters

Comparison Example

# Using group - produces a "long" table
cones.group(['Flavor', 'Price'])
Flavor Price count
Chocolate 4.75 1
Chocolate 5.25 1
Chocolate 6.55 1
Strawberry 3.55 1
Strawberry 5.25 1 
# Using pivot - produces a "wide" table
cones.pivot('Flavor', 'Price')
Price Chocolate Strawberry
3.55 0 1
4.75 1 0
5.25 1 1
6.55 1 0

Both show the same information, but pivot makes patterns easier to spot visually!

Key Takeaways

  1. Pivot creates cross-tabulations that make it easy to see relationships between two categorical variables
  2. Default behavior is to count occurrences
  3. Add values and collect to aggregate numeric data instead of counting
  4. Choose pivot over group when you want a matrix view that makes patterns visually obvious
  5. Empty cells in a pivot table mean there were no rows with that combination
WarningCommon Pitfall

Remember that pivot requires two categorical variables. If you pivot on columns with too many unique values, you’ll get a very wide or very tall table that’s hard to read!
