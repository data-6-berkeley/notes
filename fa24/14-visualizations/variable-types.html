Variable Types

Understanding different types of data and how they affect visualization choices

Suppose we have some data and want to create a visualization.

Question: How do we know what kind of visualization to create? 🤔

Answer: It depends on the type(s) of information we want to visualize.

Bar charts work sometimes, but not all the time! The type of visualization you choose should match the type of data you’re working with.

Variable Types vs. Data Types

ImportantDon’t Confuse These!

Variable types (what we’re discussing) are different from data types like string, int, Table, etc.

  • Variable types: Describe the nature of the information
  • Data types: Describe how it’s stored in the computer

When visualizing different variables (features) of a dataset, success depends heavily on understanding the types of variables you’re working with.

Understanding variable types helps us make more informed decisions when creating visualizations.

The Variable Type Hierarchy

Variable Types
├── Numerical (Quantitative)
│   ├── Discrete
│   └── Continuous
└── Categorical (Qualitative)
    ├── Ordinal
    └── Nominal

Numerical Variables (Quantitative)

Definition: Variables where you can perform meaningful arithmetic operations.

Types of numerical variables
Type Description Examples Source
Discrete Whole numbers that can be counted • Number of cars
• Number of Cal students
• Children in family		 Counting
Continuous Numbers with decimals, often measured • Price ($19.99)
• Temperature (72.5°F)
• GPA (3.85)
• Weight (150.7 lbs)		 Measuring
NoteKey Point

You can do arithmetic with numerical variables - adding, subtracting, finding averages, etc.

Categorical Variables (Qualitative)

Definition: Variables that represent categories or groups where arithmetic doesn’t make sense.

Ordinal Categorical Variables

  • Description: Categories with some inherent ordering or ranking
  • Examples:
    • Highest degree attained (High School < Bachelor’s < Master’s < PhD)
    • Yelp stars (1 star < 2 stars < 3 stars < 4 stars < 5 stars)
    • Class standing (Freshman < Sophomore < Junior < Senior)
    • Income bracket (Low < Medium < High)
  • Characteristics: There’s a meaningful “greater than” or “less than” relationship

Nominal Categorical Variables

  • Description: Categories with no inherent ordering
  • Examples:
    • Colors (red, blue, green)
    • Political affiliation (Democrat, Republican, Independent)
    • Country of origin (USA, Canada, Mexico)
    • Favorite programming language (Python, R, Java)
  • Characteristics: No meaningful ordering - one category isn’t “greater” than another

Key Point: You cannot do arithmetic with categorical variables.

Common Pitfalls

WarningWarning: Numbers Don’t Always Mean Numerical!

Just because a variable has numbers for values does not make it numerical.

Example: Area Codes

Why area codes are categorical, not numerical
Test Area Codes (510, 415, 650) Conclusion
Can you do arithmetic? 510 + 415 = ??? (meaningless) ❌ No
Is there inherent order? 415 isn’t “greater than” 510 ❌ No
Do they represent categories? Yes (geographical regions) ✅ Yes
Variable Type Categorical Nominal

Other examples of “numbers that aren’t numerical”:

Common “fake numerical” variables
Variable Why It’s Categorical
Student ID numbers Just labels for students
Social Security Numbers Personal identifiers
Zip codes Geographic categories
Jersey numbers in sports Player identifiers
TipThe Reverse Problem

Sometimes numerical variables might be stored as strings in your dataset. In that case, you’ll need to convert the values to int or float before analysis.

Why Variable Types Matter for Visualization

Different variable types require different visualization approaches:

For Numerical Variables:

  • Histograms show distribution
  • Scatter plots show relationships
  • Line plots show trends over time
  • Box plots show quartiles and outliers

For Categorical Variables:

  • Bar charts show frequency or counts
  • Pie charts show proportions (use sparingly!)
  • Stacked bars show subcategories

Mixed Types:

  • Grouped bar charts (categorical + numerical)
  • Colored scatter plots (numerical + categorical)

Key Takeaways

  1. Variable type determines appropriate visualizations - not all chart types work for all data types

  2. Numbers aren’t always numerical - consider what the numbers represent, not just how they’re stored

  3. Context matters - the same data might be treated differently depending on how you want to use it

  4. When in doubt, think about operations - can you meaningfully add, subtract, or order the values?
